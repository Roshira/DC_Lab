ВИСНОВОК

У ході реалізації та аналізу паралельної версії алгоритму Флойда-Уоршелла для знаходження найкоротших шляхів у графах можна зробити такі основні висновки:

Ефективність паралелізації
Зростання продуктивності: Алгоритм демонструє значне прискорення обчислень при використанні багатопроцесорних систем. Розподіл матриці суміжності між процесами дозволяє одночасно обробляти різні частини графа.

Масштабованість: Реалізація ефективно масштабується зі збільшенням розміру графа. Тестування на графах розміром від 10 до 1100 вершин показало здатність алгоритму обробляти великі набори даних.
