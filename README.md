Висновок:
У ході виконання лабораторної роботи було досліджено та реалізовано паралельну версію методу Гаусса-Зейделя для розв'язання задачі Діріхле для рівняння Пуассона. Порівняння ефективності паралельного та послідовного алгоритмів дозволило зробити наступні висновки:
Коректність реалізації: Результати паралельного та послідовного алгоритмів ідентичні для однакових вхідних даних, що підтверджує правильність реалізації паралельного варіанту методу Гаусса-Зейделя.
Ефективність паралелізації: Паралельна реалізація демонструє суттєве прискорення обчислень порівняно з послідовною версією, особливо для великих розмірів сітки (від 1000×1000 і більше).
Масштабування: Зі збільшенням розміру задачі ефективність паралельного алгоритму зростає, що підтверджує його придатність для розв'язання задач великої розмірності.
Обмін даними: Використання функції MPI_Sendrecv для обміну граничними рядками між процесами забезпечило ефективну комунікацію між паралельними процесами без взаємних блокувань.
Балансування навантаження: Розподіл рядків сітки між процесами з урахуванням граничних умов дозволив досягти досить рівномірного навантаження на всі процеси.
Збіжність методу: Кількість ітерацій, необхідних для досягнення заданої точності, практично не залежить від способу реалізації (паралельної чи послідовної), що підтверджує збереження властивостей збіжності методу при паралелізації.
