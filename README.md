Висновок: У даній лабораторній роботі було реалізовано послідовний та паралельний алгоритми Гауса для розв'язання систем лінійних рівнянь. Паралельна версія алгоритму була розроблена з використанням бібліотеки MPI та заснована на розподілі даних між процесами за схемою блокового смугового розподілу матриці. Експерименти підтвердили коректність роботи алгоритмів та продемонстрували можливість прискорення обчислень за рахунок паралелізму, особливо для систем великої розмірності.
